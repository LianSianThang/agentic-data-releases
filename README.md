# Agentic Data Desktop

Official public downloads for the fully local Windows edition of Agentic Data.

## Download

Open the latest GitHub Release and download the Windows EXE. An MSI and SHA-256 checksums are also provided.

## Local and private

- Runs entirely on your Windows computer
- No Agentic Data cloud backend or Supabase account required
- Data, models, RAG indexes, and chats stay local
- Bring your own LLM API key (BYOK)
- Embedded processing listens only on 127.0.0.1

See INSTALLATION.md, PRIVACY.md, and RELEASE_NOTES.md.
