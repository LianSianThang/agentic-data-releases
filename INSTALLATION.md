# Installation

1. Download the EXE from the latest release.
2. Run the installer and follow the Windows prompts.
3. Start Agentic Data from the Start menu.
4. Open Settings and add your own LLM provider API key.
5. Create an ML, RAG, or Hybrid workspace.

The first launch may take up to 60 seconds while the embedded local engine starts. The MSI package is available for managed installation.
