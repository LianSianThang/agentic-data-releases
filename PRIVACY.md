# Privacy

Agentic Data Desktop runs locally. Workspaces, uploaded files, trained models, document indexes, and chat history remain on the user's computer. The embedded engine binds only to 127.0.0.1 and stops when the application closes.

LLM requests are sent only to the provider selected by the user with the user's own API key. Provider privacy and billing terms apply. Agentic Data does not provide or proxy the desktop user's API key.
